# Guess the Card 🃏

Et gættespil til mobilen, bygget i React Native (Expo). Du ser et Magic: The Gathering-kort, hvor navnet
er dækket til, og skal skrive kortets navn. Du har 5 liv. Efter hvert gæt afslører en animation det rigtige navn.

## Funktioner (planlagt)

- Tilfældige kort hentet fra [Scryfall API](https://scryfall.com/docs/api)
- Navnet på kortet er dækket til og afsløres med en animation efter hvert gæt
- 5 liv, score og game over
- Login med Firebase Auth
- Highscore-liste gemt i Firebase Firestore

## Teknologi

React Native · Expo · React Navigation · Reanimated · Firebase (Auth og Firestore) · Scryfall API

## Kom i gang

> Projektet er ikke oprettet endnu. Vejledningen opdateres, når Expo-projektet findes.

```bash
npm install
npx expo start
```

Scan QR-koden med **Expo Go** på en Android- eller iOS-telefon.
